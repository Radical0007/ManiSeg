# 实验配置与评估流程

[返回首页](../README.md) · [方法与算法](method.md) · [实验结果](experiments.md)

MC3WD-SEGBC 的评估流程包括目标实例准备、联合训练、特征提取、语义熵粒化、碰撞检测、三支空间划分和投影保真度计算。

## 数据与表示

实验使用 COCO 中的 person、bicycle、motorcycle、car、bus、truck、bottle、cup、bowl 共 9 个类别，包含 16,873 个目标样本。每个目标由图像、标注框和类别标签组成，按标注框裁剪并调整至 224 的裁剪大小。

| 表示 | 形状 | 内容 |
| --- | --- | --- |
| 特征矩阵 X | N × d | 全局平均池化后的实例级高维特征 |
| 概率矩阵 P | N × C | 各实例在 C 个类别上的预测概率 |
| 投影矩阵 Y | N × 2 | 实例特征的二维投影 |
| 终端粒球集合 | M 个粒球 | 球心、有效半径、平均预测分布和主导语义 |
| 三支区域 | POS、BND、NEG | 每个实例的覆盖与碰撞归属 |

特征、概率与投影中的同一行对应同一个目标实例。

## 评估步骤

1. **准备目标实例**：从标注图像中裁剪目标区域，建立实例与类别的对应关系。
2. **联合训练与流形对齐**：通过复合损失优化训练模块，获得用于特征评估的网络。
3. **提取高维表示**：在目标层提取局部特征图，全局平均池化得到 X，同时收集预测概率 P。
4. **构建语义粒球**：计算质心、95% 分位数半径与平均预测分布，以语义熵和信息增益驱动递归二元分裂。
5. **检测异类碰撞**：遍历主导语义不同的终端粒球对，使用中心距离与半径和判定碰撞关系。
6. **划分三支空间**：根据样本实际覆盖和异类碰撞对，生成 POS、BND、NEG 区域。
7. **生成低维投影**：将高维实例特征映射至二维空间，展示类别结构、三支区域与碰撞点。
8. **计算投影保真度**：由高低维邻域秩计算 GTF，由低维邻域中的预测概率相似度计算 SNH，结合权重得到 VSF，并计算多尺度 AUC。
9. **汇总实验结果**：对照检测精度、轮廓系数、投影保真度、边界率、多重覆盖率与风险覆盖指标，分析模型与模块之间的差异。
